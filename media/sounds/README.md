# Звуки

## Озвучка фраз

Озвучка лежит в папке персонажа, `media/characters/<id>/`. У Нацуки (`media/characters/natsuki/`)
у каждой фразы есть своя озвучка — она играет вместе с этой фразой в облачке:

| Файл             | Фраза                                   |
|------------------|-----------------------------------------|
| `voice-0.wav`    | Хозяин, ошибка!                         |
| `voice-1.wav`    | Хозяин, там опять красненькое!          |
| `voice-2.wav`    | Ой-ой, что-то сломалось…                |
| `voice-3.wav`    | Хозяин, компилятор ругается!            |
| `voice-4.wav`    | Хозяин, что-то не так~                  |
| `voice-5.wav`    | Не волнуйтесь, хозяин, вы справитесь!   |
| `voice-test.wav` | Хозяин, это всего лишь проверка~        |

Голос склонирован в [Voicebox](https://github.com/jamiepine/voicebox) (Qwen3-TTS 1.7B,
seed 42) по образцу из TikTok-ролика. Для живой интонации текст озвучки чуть отличается
от фразы в облачке: добавлены междометия («Эх…», «Ой!», «Хи-хи!») и восклицания.
Номер — индекс фразы в `phrases` из `character.json` персонажа.

## Остальные звуки

Если озвучки нет (свои фразы из `kawaiiError.phrases` или персонаж без голоса, как Курилов), играет звук по
префиксу имени. Сейчас это простые сгенерированные бипы (`node scripts/gen-placeholder-wav.mjs`).
Если таких файлов несколько, берётся случайный:

| Префикс     | Когда звучит                               |
|-------------|--------------------------------------------|
| `error*`    | новая ошибка (диагностики, задача, терминал, отладка) |
| `warning*`  | предупреждение                            |
| `test*`     | команда «Kawaii: Test reaction»            |

Пример: `error-1.wav`, `error-nyaa.wav`, `test-1.wav`.

Если подходящего файла нет, играет любой `.wav` из папки.

Чтобы не трогать папку расширения (она перезаписывается при обновлении), укажите
свою папку в настройке `kawaiiError.sound.directory`: она проверяется первой.

Формат: обычный PCM WAV. На Windows используется `System.Media.SoundPlayer`,
который понимает только WAV.
