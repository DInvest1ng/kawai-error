# Changelog

## 0.1.2

- Новый аватар: розоволосая девочка в школьной форме (PNG с прозрачным фоном)
  вместо SVG-плейсхолдеров — все пять эмоций и иконка маркетплейса.

## 0.1.1

- Отладка: реакция и тогда, когда программа под отладчиком просто падает с ненулевым кодом
  (Node-отладчик по умолчанию не останавливается на непойманных исключениях).
- Упавшая задача теперь подписывается как «Задача», а не «Терминал» (оба события склеиваются в одну реакцию).
- Интеграционные тесты в настоящем VS Code: `npm run test:integration`.

## 0.1.0

- Первая версия: вебвью-панель с девочкой-плейсхолдером, облачко с репликой и звук.
- Детекторы: диагностики (рост числа Error, режим onlyOnSave), задачи, команды терминала, исключения в отладчике.
- Шина ошибок с debounce и cooldown, настройки звука, своих спрайтов, реплик.
